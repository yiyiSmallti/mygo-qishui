# 汽水音乐插件使用指南

把汽水音乐账号接入 MyGo Music，使用音乐库、搜索、歌词、推荐和场景电台。当前 **0.6.8** 兼容原版 **MyGo Music v0.1.22**，播放无需 FFmpeg；Windows 小图标布局和任务栏播放条可按需安装。

**0.6.8 的 Apple Silicon Mac 无需安装汽水客户端。** 首次会从官方精简归档自动准备组件，之后可复用缓存。

Windows 用户已于 2026-11-10 实机测试 0.6.7，反馈暂未发现问题。Apple Silicon Mac 已完成已有会话播放、内嵌取码和隔离场景检查。历史版本及验证范围见 [历史记录](../docs/history.md)。

## 可以做什么

- 账号头像、昵称、登录状态保存和退出登录。
- 自建歌单、收藏歌单、喜欢的音乐、抖音收藏和收藏专辑；首页及「音乐库」提供对应入口与刷新操作。
- 歌曲、专辑、艺人、歌单四类搜索，支持继续加载结果。
- 歌单详情、专辑曲目、艺人作品，以及上传者资料。没有专辑 ID 的上传作品仍显示可用封面和标题。
- 逐行、逐字歌词，使用汽水返回的时间信息。
- 播放当前账号获得完整授权的歌曲和上传原声，保留 AAC-LC／FLAC 原编码，并检查完整时长，无需 FFmpeg。
- 推荐首页、“换一批推荐”、连续推荐与场景电台；推荐暂时不可用时仍显示原有音乐库。
- 心形按钮读取真实的歌曲喜欢状态；点击后添加或取消汽水账号中的喜欢，支持普通歌曲和上传原声。

“听歌模式”用于选择推荐内容；顺序、随机、循环仍由 MyGo 的播放控制栏设置。Windows 任务栏迷你播放条属于可选界面增强，可通过随包的增强管理助手安装。拖动封面或歌词区域可选择左侧或右侧的可用位置；右上角关闭按钮隐藏播放条，音乐继续播放，可在设置中重新开启。有真实逐字时间的歌词显示逐字高亮，仅有整行时间的歌词按行显示。此任务栏播放条尚未移植到 macOS。

播放、推荐和页面浏览只读取资料，不修改远端收藏。只有点击心形按钮（或主动使用 MyGo 的对应快捷键）才会添加或取消汽水账号中的喜欢；歌单和专辑收藏仍为只读。在手机上修改后，可在插件中选择「刷新音乐库」。

## 安装、更新与登录

| 系统 | 发布附件 | 本机准备 |
| --- | --- | --- |
| Windows x64 | `plugin-windows-amd64.zip` | Node.js 24+、WebView2 Runtime；所需汽水组件可自动准备 |
| macOS Apple Silicon | `plugin-darwin-arm64.zip` | ARM64 Node.js 24+；自动准备汽水组件，网页运行时由系统提供 |

首次在 MyGo「设置 → 插件 → ＋ → 从 GitHub 安装」输入 `yiyiSmallti/mygo-qishui`。从本机安装时，请到 [0.6.8 发布页](https://github.com/yiyiSmallti/mygo-qishui/releases/tag/v0.6.8) 下载对应平台 ZIP；源码 ZIP 用于查看或构建，不是插件安装包。

启用插件并允许运行辅助程序，然后在账号菜单选择汽水音乐登录。用手机汽水 App 扫码确认，需要安全验证时在插件自带的登录窗口继续。成功后窗口自动关闭；提前关窗会取消本次登录，原账号保留。

已有 GitHub 来源插件，在 **汽水插件菜单 → 检查更新** 中升级。本机来源插件重新下载对应 ZIP 升级。保留插件数据目录，已有登录和有效缓存可继续使用，无需为更新重复扫码。

### 可选 Windows 界面增强

Windows 包包含增强管理助手，可安装小图标听歌模式、紧凑推荐页、插件设置入口和任务栏播放条。原版 MyGo 首次从汽水侧栏「界面增强 → 打开增强管理」进入；安装后从「设置 → 插件 → 汽水音乐 → 界面增强」打开。助手识别兼容程序，确认后备份、更新并重启 MyGo，未知构建会提示兼容性问题。

任务栏播放条在 MyGo 设置中启用，管理窗口的“已安装”表示组件已具备，不代表播放条已开启。官方 MyGo 更新可能覆盖界面增强，可再打开助手检查；手动构建与回退见 [增强说明](../patches/README.md)。

## 播放与加载方式

播放只使用汽水向当前插件账号返回的完整音频。服务器未提供完整播放信息或时长不足时，插件会报告无法播放，不把试听片段当作整首歌曲。

0.6.7 的播放路径已改为插件内置的 **CENC 解密**，保留汽水返回的原始 AAC-LC／FLAC 编码和 MP4 容器，以 `.m4a` 缓存交给 MyGo 解码，不再转码或调用 FFmpeg。0.6.6 及更早版本仍使用旧的 FFmpeg 路径。

解密使用 Node.js 内置 `crypto`，播放密钥仍由汽水向当前账号返回的授权和官方组件取得，不写入缓存或日志。仅接收已支持的完整单音轨 MP4、CENC AES-CTR、8／16 字节 IV 和分段加密；未知加密方式、分片 MP4、密钥轮换或当前 MyGo 不支持的 AAC 规格会明确提示，不能用文件扩展名替代格式校验。MyGo 无需修改主程序。

缓存会核对完整时长、采样范围和 SHA256；半成品不会用于播放，并发请求只发布一个完整缓存。旧版生成的有效 FLAC 缓存可在重新核对当前账号的完整播放授权后继续使用。界面音质按服务端实际提供的源音质标记，文件名 `.m4a` 不代表有损或无损。

音乐库按汽水接口游标分页，并去除重复条目。当前单个歌单最多载入 5000 首，歌单/收藏列表最多 2000 项。歌单暂未加载完整时会显示说明，重新打开可继续加载；搜索结果过多时可缩小关键词范围。网络较慢或文件较大时，可稍后重试或选择较低音质。

## 本机依赖

0.6.7 播放无需安装 FFmpeg；Node.js 和下述汽水组件仍需准备。登录使用插件自带的内嵌窗口，Windows 需要 WebView2 Runtime，Mac 使用系统 WebKit，无需单独安装 Chrome／Edge。Windows x64 和 Apple Silicon Mac 可自动从官方归档提取汽水组件，无需安装或启动完整汽水客户端；仓库和插件 ZIP 不附带汽水官方原生 SDK。安装后需在 MyGo 中授予此插件「运行程序」权限，辅助进程负责设备准备、签名请求和音频解密，扫码与验证由插件登录窗口完成。

### Node.js 路径设置

插件设置中的「Node.js 路径」为可选项：填写 `node.exe`（Windows）或 `node`（macOS）的完整路径，可包含空格，不需要加引号；留空使用下方的自动查找顺序。设置后登录、搜索歌单、歌词和播放辅助程序共用该运行时。

Windows 可在 PowerShell 中运行 `where.exe node` 查找当前安装位置，macOS 可运行 `command -v node`。使用 nvm／fnm 或自定义安装目录时，可把期望使用的 Node.js 24 或更新版本路径填入设置。修改 `PATH` 后需重启 MyGo，让它继承新的环境。

只有找不到可执行文件时才尝试下一个自动候选位置。填写了自定义路径但文件不存在时会提示检查设置；未授予「运行程序」权限或启动被系统拒绝时保留相应错误。

### macOS（Apple Silicon 已验证）

- **Node.js 24 或更新版本**：依次尝试 `/opt/homebrew/bin/node`、`/usr/local/bin/node` 和 `PATH` 中的 `node`。从 Finder／Dock 启动 MyGo 时通常没有交互式 shell 的 `PATH`，仅安装在 nvm 等私有目录的 Node.js 可能无法找到。
- **音频解密**：由插件与 Node.js 内置模块完成，无需 FFmpeg。已有 Homebrew 时可运行 `brew install node`；0.6.6 及更早版本仍需另行安装 FFmpeg。
- **内嵌登录**：使用系统 WebKit，由插件自带登录组件显示，无需外部浏览器。
- **汽水组件自动准备**：首次登录或播放时，从汽水官方 CDN 下载固定的 **3.7.0 ARM64 精简归档**（约 18 MiB），校验整个归档的 SHA256，再用系统 `/usr/bin/tar` 只提取 `app.asar`、`device.node`、`bdms.node` 和 `libMetaSecML.dylib`。不安装或运行 `.app`，无需挂载 DMG；每个文件还会核对 SHA256 与 Mach-O 架构。
- 提取后的组件存放在本插件数据目录的 `native-sdk-3.7.0-darwin-arm64`，约占 9.4 MiB；有效缓存可离线复用。首次归档、提取半成品和准备锁在完成或取消后清理。已有官方客户端也不会被修改，原账号与音乐缓存保留。
- **旧版 0.6.7**：尚未包含 Mac 自动准备流程，仍需安装到 `/Applications/汽水音乐.app` 或 `~/Applications/汽水音乐.app` 的汽水音乐 3.7.0 组件。

Mac 免安装流程需要 ARM64 Node.js 24 或更新版本；Node.js 安装在其他位置时，可在插件设置中填写路径，无需设置汽水客户端位置。Intel Mac 尚无已验证的自动准备安装包。

精简归档来自 [汽水官方 3.7.0 ARM64 下载地址](https://lf-luna-release.qishui.com/obj/luna-release/3.7.0/452316191/SodaMusic-v3.7.0-official-darwin_arm64.tgz)，固定大小 `19001509` 字节，SHA256 为 `40c6bc80aa32cd1d5c76ad1b05bccc67e5ec22cf779b6dc3617ee5432b88ee04`；来源对应官网公开下载设置中的 `darwin.arm64.smallPackage`。

### Windows x64

Windows x64 支持免安装组件准备：

- Node.js 24 或更新版本：优先使用 `PATH` 中的 `node`，找不到时再尝试 `C:\Program Files\nodejs\node.exe`；也可在插件设置中指定完整路径。
- **内嵌登录**：插件登录组件使用 WebView2 Runtime，缺少时需安装微软 WebView2 Runtime；不查找或启动 Edge／Chrome 可执行文件。
- **汽水组件免安装**：未找到完整的官方客户端组件时，首次登录或请求播放信息会从汽水官方 CDN 下载固定的 **3.7.0 x64** 安装包（约 144 MiB），校验 SHA256，再用系统 `tar.exe` 提取 `app.asar`、`device.node`、`bdms.node` 和 `metasecml.dll`。**不运行安装包，不创建官方客户端快捷方式或自启动项**。已有客户端时，查找 `%LOCALAPPDATA%\Programs\Soda Music`、`%ProgramFiles%\Soda Music` 和 `%ProgramFiles(x86)%\Soda Music` 中完整的安装目录，按版本由新到旧选择。
- 免安装需要 **x64 Node.js** 和支持读取此 7z 归档的 Windows 系统 `tar.exe`。新版 Windows 11 有相应能力；旧版 Windows 的归档工具可能不支持，此时会提示更新 Windows 的归档工具。下载失败、哈希不符、磁盘权限等问题会单独报告，不清除已有登录。
- 提取的组件存放在本插件数据目录的 `native-sdk-3.7.0-x64`，校验通过后重复使用；有效缓存无需再次下载。下载的完整安装包和解包临时文件会在完成或取消后删除。并发请求会等待同一次准备完成。
- **音频解密**：0.6.7 已包含所需模块，播放无需 FFmpeg 或额外解密程序。Node.js 与汽水签名／授权组件仍需按上述方式准备。

下载固定指向 [汽水官方 3.7.0 x64 安装包](https://lf-luna-release.qishui.com/obj/luna-release/3.7.0/452316191/SodaMusic-v3.7.0-official-win32_x64.exe)，整体 SHA256 为 `e58578aec410e2c9c24835e92a1dc74d0fda982be1cf1003034538255baab0e4`，与 [Microsoft winget 3.7.0 清单](https://github.com/microsoft/winget-pkgs/blob/master/manifests/b/ByteDance/SodaMusic/3.7.0/ByteDance.SodaMusic.installer.yaml) 一致。仅提取与校验官方字节，不修改签名算法或上传账号到第三方服务。系统归档支持参考 [Microsoft tar 文档](https://learn.microsoft.com/en-us/windows/tar/)。

两端均不需要启动官方汽水客户端，也不读取它的账号资料或现有登录凭据。辅助进程会访问汽水 API、官方安全 SDK/CDN 及音频 CDN；Windows 与 Mac 首次准备还会访问 `lf-luna-release.qishui.com`。

## 登录、存储与退出

登录前仅由 Node.js 准备插件设备。随后插件登录组件创建临时隔离 WebView，加载官方安全 SDK、获取二维码并轮询。二次验证沿用同一次二维码、Cookie 与请求信息，成功回调后接续原请求；插件再通过汽水 API 校验账号，校验成功才保存新会话。失败、超时、关闭窗口都保留原账号。
- 登录凭据由 MyGo `host.storage` 保存在本机插件数据的 JSON 文件中，不是系统加密凭据库；无需手动提供密码或 Cookie，不应分享该数据文件。
- 「退出登录」清除此插件的本地账号凭据和内存音乐库缓存，并取消插件正在进行的登录/媒体请求。不会退出手机或官方客户端，也不撤销其登录。
- 插件自己的匿名设备身份会保留，供下次登录复用。
- 音频缓存使用 MyGo 提供的插件数据目录：Windows 通常为 `%APPDATA%\MyGo Music\plugin-data\qishui-account\media-cache`，macOS 为 `~/Library/Application Support/MyGo Music/plugin-data/qishui-account/media-cache`。缓存按账号、歌曲和源音质区分；插件会在后续播放时清理较旧文件，目标总量不超过 512 MiB；退出账号不删除已有音频缓存。
- 内嵌窗口使用临时会话，不读取系统浏览器或官方客户端的账号。远程页面不能调用 MyGo 的 Go 服务；官方验证需要的弹窗仍由插件登录组件显示，并共用本次临时会话。完成或取消后关闭相关窗口。
- 原版 MyGo 的对话框“取消”仅关闭该对话框；需取消登录时关闭插件登录窗口，或退出登录。组件本身设置独立时限，超时后会退出。「退出登录」仍会清除本插件的原账号。若验证成功后平台再次要求验证，停止本次请求并提示稍后重试，避免循环取码。

## 验证与常见问题

Windows 0.6.7 已收到用户“实机测试暂未发现问题”的反馈，人工反馈与自动化检查分别记录。0.6.8 已通过 8 项 Mac 组件准备检查、8 组私有组件真实播放检查及 2 项 Windows 准备锁回归，官方客户端访问次数为 0。既有记录另包含 130 项插件回归、21 项加密样本校验和 8 组隔离播放流程；详细范围及历史记录见 [docs/history.md](../docs/history.md)。

- **还需要 FFmpeg 吗？** 0.6.7 播放不需要；Node.js 仍需准备；新版可自动下载并校验汽水签名／授权组件。
- **需要换 MyGo 主程序吗？** 登录与播放可直接使用原版 0.1.22；小图标布局、设置动作和 Windows 任务栏组件属于可选增强。
- **手机已经确认，为什么还要验证？** 是否需要额外验证由汽水决定，请在插件登录窗口中完成官方验证；不要提前关闭窗口。
- **歌曲显示不可播放怎么办？** 部分歌曲或视频作品可能未向当前账号提供完整音频；插件会明确提示，不把试听当作整首。
- **更新后找不到变化？** 确认更新的是汽水插件、选择了正确平台包，并核对显示版本为 0.6.8。可选界面增强需在助手中确认安装。

在项目根目录运行 `npm test` 可执行模拟回归；其余验证脚本及源码入口见 [开发与验证](../README.md#开发与验证)。
