## 0.6.8 · 2026-11-10

Apple Silicon Mac 新增固定官方 3.7.0 精简归档的自动下载、校验与提取，只保留四个必需文件。首次下载约 18 MiB，组件缓存约 9.4 MiB，不安装或启动官方客户端，不挂载 DMG，也不读取其账号。Windows 现有流程继续保留。

同时修复并发恢复旧准备锁时，将另一个刚建立的恢复锁误判为中断的问题。8 项 Mac 组件准备检查、8 组私有组件真实播放检查、2 项 Windows 准备锁回归及 130 项插件回归通过。检查使用隔离目录，屏蔽官方客户端路径后验证匿名设备注册、三档完整音频及定位，正式账号存储哈希未变。复现入口为 `scripts/verify-mac-sdk.mjs` 和 `scripts/verify-live-media.mjs`。

## 0.6.7 · 2026-11-10

当时的 Mac 版本尚未自动准备组件，需要本机汽水音乐 3.7.0；0.6.8 起已取消此安装要求。0.6.6 及更早版本的播放路径还依赖 FFmpeg。以上仅说明旧版依赖，当前安装方式见 [使用指南](../qishui-account/README.md#本机依赖)。

新增内置 CENC 解密，保留 AAC-LC／FLAC 编码与 MP4 容器，播放无需 FFmpeg。130 项插件回归、21 项加密样本校验和 8 组隔离完整流程通过；原版 MyGo 更新接口已检测、下载并加载 0.6.7。

用户于 2026-11-10 反馈：已在 Windows 实机测试 0.6.7，暂未发现问题。本条为人工使用反馈，与自动化检查分别记录。

发布前的 Mac 扩展联网复测曾在音频下载阶段返回 `ECONNRESET`；该记录是当时的网络结果。发布附件 `verification.json` 保留发布时的自动化记录，之后的用户反馈在 README 与发布页补充。

## 先前版本变更

**0.6.6** 将经典系统提示框替换为 MyGo 原生增强管理窗口，支持深浅主题，并显示听歌模式、插件设置入口和任务栏播放条的状态。Windows 增强包已包含任务栏组件，确认后一次备份、更新并重启主程序；0.6.5 的旧增强版可直接确认升级。安装后从「设置 → 插件 → 汽水音乐 → 界面增强」打开管理窗口，侧栏的重复入口会隐藏；原版首次仍保留侧栏入口。任务栏播放条可在 MyGo 设置中开启或关闭。

**0.6.5** 修复 0.6.4 漏识别官方 Windows x64 MyGo 0.1.22 的问题：官方程序 SHA256 为 `9e49bc806c3cff513c628fe40e94285c5388634e44bb333a4c21dc0dff555482`，来自已校验的 [上游 v0.1.22 发布包](https://github.com/egoist/mygo-music/releases/tag/v0.1.22)。安装增强后，「设置 → 插件 → 汽水音乐」中提供真正的「界面增强」按钮，无需切换当前音源或登录账号。原版 MyGo 的设置页尚无动作接口，因此首次仍从现有侧栏入口安装一次主程序支持；0.6.4 的旧增强程序也可确认升级。未知构建继续拒绝覆盖，提示中显示实际路径与 SHA256；备份及回退按实际原程序哈希验证。

**0.6.4 已将 Windows 小图标样式增强随插件打包。**更新后打开汽水插件侧栏的「界面增强 → 打开增强管理」，由助手核对程序；已是当前增强版本时不会重复更新，未安装时只有确认后才备份、关闭并重启 MyGo。无需另找播放器安装包或运行脚本。暂限已验证的 Windows x64 MyGo 0.1.22 构建；未知程序会拒绝修改。Mac 不带 Windows 增强组件，仍可正常使用音源。

0.6.3 修复现代二次验证界面空白：插件内置 React / ReactDOM 18.3.1，并在加载官方验证组件前注入所需全局变量，无需额外连接 React CDN。

0.6.2 修复 Windows 登录窗口因 API 根目录返回 HTTP 404 而报 `load`：Windows 组件在临时 WebView 内提供本地同源宿主页，官方 SDK 与接口请求继续通过正常 HTTPS 连接，不忽略实际的导航失败。

0.5.2 修复官方 `auth.zijieapi.com` 二次验证入口被误拦截的问题，并在入口被拒绝时显示公开域名与固定原因；诊断不保存 URL 路径、查询参数、账号信息或票据。

0.5.1 包含 Mac 依赖查找、插件数据目录缓存及播放平台参数修复，新增 Node.js 路径设置、Windows 免安装组件、系统扫码设备名和官方二次验证接续。Intel Mac 尚未实机验证；Linux 暂不支持。

0.5.0 按参考界面重新整理「听歌模式」：常用模式采用小图标横卡，探索电台采用封面、标题与简介叠放的宽卡，剩余场景保留在「更多听歌模式」。小图标使用独立 `iconUrl` 字段并随主题着色；原有 `imageUrl` 彩底封面保留，未使用新布局的播放器仍能正常显示封面。配套 MyGo 补丁增加任务栏大字逐字歌词、左右拖拽停靠和关闭按钮。

0.4.2 整理推荐页：换一批操作紧随推荐歌曲，连续听歌使用紧凑横卡，场景、电台和歌单各显示少量预览，并通过“查看全部”打开完整内容。推荐刷新保持摘要结构；音乐库导航与刷新使用操作入口，不再冒充无封面的歌单卡。紧凑布局及强制刷新行为由配套 MyGo 0.1.21 界面补丁支持；未安装该补丁时仍兼容原有卡片展示。

0.4.1 修复听歌模式封面：场景接口返回的是白色透明图标，不能使用歌曲封面的 JPEG 裁剪方式。现将 45 个官方场景图标、熟悉与新鲜模式图标制成带底色的本地 PNG，个性推荐使用音频图形；未知的新场景使用通用模式封面。封面随插件安装，兼容深浅主题，不依赖图片 CDN。发现电台、歌单及歌曲仍保留各自的真实封面。

0.4.0 新增推荐首页、个性推荐／熟悉／新鲜模式、汽水当前提供的场景和发现电台。点击电台后由 MyGo 自动补充下一批歌曲。推荐内容从当前账号获取，不伪造收听记录。顶部“喜欢的音乐”是唯一的喜欢入口，不再重复显示同名歌单卡；“收藏专辑”和“抖音收藏”保留各自来源。

0.3.1 修复实机播放检查发现的上传原声兼容问题：保留官方 `ugc_clip` 媒体类型，按该作品的实际时长检查完整音频。视频作品暂不支持播放。平台未返回音频的歌曲仍会显示不可播放。
